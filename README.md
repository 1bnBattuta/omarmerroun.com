# omarmerroun.com

Personal blog where I post projects overviews, technical posts, and any interesting topic I found.

**Stack:** [Hugo](https://gohugo.io) · [terminal theme](https://github.com/panr/hugo-theme-terminal) · deployed on [Cloudflare Pages](https://pages.cloudflare.com)

**Live:** https://omarmerroun.com

## Local development
hugo server: Posts live in `content/posts/`. Set `draft: false` in front matter to publish on next deploy.
